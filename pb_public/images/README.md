# Custom Icons Directory

Place your custom application icons in this directory.

## Required Icons

### Transit App
- `mototaxi-icon.png` (32x32 pixels) - Mototaxi vehicle icon
- `bus-icon.png` (40x32 pixels) - Bus vehicle icon

### Fishing App  
- `panga-icon.png` (32x32 pixels) - Small fishing boat icon
- `boat-icon.png` (40x40 pixels) - Medium boat icon
- `yacht-icon.png` (48x48 pixels) - Large yacht icon

### Travel Map
- `treasure-chest.png` (32x32 pixels) - Hidden gem marker
- `attraction-icon.png` (40x40 pixels) - Cultural attraction marker

## Icon Guidelines

- Use PNG format with transparent backgrounds
- Keep file sizes small for performance
- Use consistent color schemes
- Test visibility on map backgrounds
- Consider both light and dark map themes

## Creating Icons

You can create these icons using:
- Online icon generators (favicon.io, etc.)
- Image editing software (GIMP, Photoshop)
- Icon design tools (IconJar, Figma)
- AI image generators (DALL-E, Midjourney)

## Temporary Solution

Until custom icons are ready, the system will use:
- Leaflet default markers
- Emoji icons (🗿, 🏛️, 💎, etc.)
- CSS-styled markers

The application will function without these custom icons, but they enhance the visual experience.
